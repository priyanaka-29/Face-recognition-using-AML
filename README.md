# Face Recognition System

A real-time face recognition system developed using a webcam for face detection and recognition.

## 📌 Project Overview

This project captures faces through a webcam and performs real-time face recognition using image processing and machine learning techniques.

## 🚀 Features

- Real-time face recognition using a webcam
- Image processing using OpenCV and NumPy
- Face recognition using TensorFlow
- Approximately **95% accuracy**
- Improved real-time recognition performance

## 🛠️ Technologies Used

- Python
- OpenCV
- TensorFlow
- NumPy

## 🔄 Workflow

```text
Webcam
   ↓
Capture Face
   ↓
Image Processing
   ↓
Face Recognition
   ↓
Recognized Face
```

## 📊 Performance

The system achieved approximately **95% accuracy** and improved real-time face recognition performance.

## 💡 Applications

- Face-based identification
- Security systems
- Attendance systems
- Real-time user recognition
