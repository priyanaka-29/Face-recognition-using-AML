# Face Recognition System

A real-time face recognition system built using a webcam.

## Features
- Built a real-time face recognition system using a webcam.
- Used **OpenCV, TensorFlow, and NumPy** for image processing and face recognition.
- Achieved approximately **95% accuracy** and improved real-time recognition performance.

## Technologies Used
- Python
- OpenCV
- TensorFlow
- NumPy
